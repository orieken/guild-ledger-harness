# Repair stage

Use the original assigned request, coding guidelines, bounded workflow, candidate snapshot, visible-check evidence, and validated review. Correct supported findings within the original edit scope; do not add requirements absent from the assigned prompt. If a finding is unsupported or cannot be resolved, record why with evidence. Run appropriate visible checks. Return findings addressed, findings remaining, files changed, and commands with observed results. This is the final repair pass; do not start another review or agent.
